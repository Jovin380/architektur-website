# SEO- und KI-Such-Skills

Agent-Skills für Suchmaschinenoptimierung (SEO) und Optimierung für KI-Suche (GEO/AEO). Claude Code lädt sie
automatisch, wenn in diesem Repo gearbeitet wird. Alle unter MIT-Lizenz, unverändert übernommen (Stand 17.11.2026):

| Skill | Wofür | Quelle |
|---|---|---|
| `seo-geo`, `seo-local`, `seo-schema`, `seo-technical`, `seo-content`, `seo-page` (+ `seo/references`) | KI-Suche, lokales SEO (Google-Unternehmensprofil, NAP), strukturierte Daten, Technik, Inhalte, Seitenanalyse | [AgriciDaniel/claude-seo](https://github.com/AgriciDaniel/claude-seo) |
| `geo-citability`, `geo-llmstxt`, `geo-crawlers`, `geo-schema` | Zitierfähigkeit für ChatGPT, Perplexity und Claude, llms.txt, KI-Crawler in robots.txt, Schema | [zubair-trabzada/geo-seo-claude](https://github.com/zubair-trabzada/geo-seo-claude) |
| `ai-seo`, `schema`, `site-architecture` | KI-Suche, Schema-Markup, Seitenstruktur und interne Verlinkung | [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills) |

Einige Skills verweisen auf Skripte oder kostenpflichtige Datenquellen (DataForSEO, Ahrefs) aus ihren
Original-Repos; die Anleitungen funktionieren auch ohne sie.
